# Pradhan by Panchayat — Letter concept

A responsive design prototype built around a letter, postage-stamp collection cards, and original illustrations of village life and craft.

The homepage introduces the brand philosophy and collection stories. Collection pages contain illustrative garment silhouettes and a demonstration of a short checkout path. This is a design preview; ordering and payments are not enabled.

Built with static HTML, CSS, and a small amount of JavaScript on the collection page. All asset paths are relative so the site works on GitHub Pages project URLs.

## Preview locally

Run `python -m http.server 4173` in this directory, then visit `http://localhost:4173`.

## Deployment

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the site. `.nojekyll` preserves the static files without Jekyll processing.
